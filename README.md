# Python: домашнее задание №3

Темы: строки, списки, словари, множества, кортежи; функции, параметры, возвращаемые значения, область видимости; разбиение задачи на шаги.

## Как выполнять

1. Клонируй этот репозиторий на компьютер.
2. Открывай файлы по порядку от 1 до 7. Условия находятся в начале файлов и в описаниях функций.
3. Замени `pass` своим кодом. Готовых решений в репозитории нет.
4. Функции должны возвращать результат через `return`, если условие не просит вывести текст.
5. Примеры в условиях — ориентиры для проверки. Добавь собственные примеры, включая пустые данные.
6. Запускай файлы, например: `python 1_strings.py`. Можно перенести упражнения в Jupyter Notebook.
7. Сделай commit и push с решениями.

Нужен Python 3.10 или новее. Внешние библиотеки, pandas и чтение файлов не нужны.

| Файл | Тема |

## Критерии самопроверки

- Условия выполнены, примеры дают ожидаемый результат.
- Пустые коллекции обработаны там, где это требуется.
- Исходные коллекции не изменяются без прямого указания.
- Функции используют параметры, а не скрытые глобальные зависимости.
- Понятные имена, небольшие функции, нет дублирования.
- В итоговом задании есть план и отдельные функции для шагов.

В этих заданиях **churn = 0 — клиент ушёл, churn = 1 — клиент остался**.
